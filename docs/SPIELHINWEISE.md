# Ein Tag als Ranger / Feldbuch

Wähle **Freie Erkundung** oder **Lernmissionen**. Zusätzliche Begegnungsszenarien
bleiben auf der Startseite erreichbar. Fernglas: Tiere; Lupe: Pflanzen. Ein
Programmname ist eine Information, keine selbständige Bestimmungsleistung. Die
Missionen dokumentieren Merkmale, Belege, Herkunft und Einordnungen im Feldbuch.

Kein Konto, Spielserver oder Datenbank nötig. Das Feldbuch liegt lokal im Browser.
Bei Speicherfehlern erscheint ein Hinweis. Sichere JSON vor Geräte-/Sitzungswechsel;
importiere nur vertrauenswürdige eigene Exporte. Der druckbare Feldbericht enthält
offene Begründungen. Sie werden nicht von einer KI oder per Wortsuche benotet.
Spieltempo und Sammelzahlen sind keine Note.

Die Welt ist ein Lehrmodell. Freie Sichtungszahlen sind keine Naturmessungen.
Virtuelle Wattproben erlauben keine reale Entnahme. Nationalparkregeln, Wetter
und Gezeiten beachten; reale Wattgänge nur fachkundig begleitet planen.
Weitere Grenzen: `MODELLGRENZEN.md`; Unterrichtsvorschläge: `LEHRKRAEFTE.md`.

Spielmedien werden vom selben Ursprung geladen. Quellenlinks werden erst auf
ausdrücklichen Klick besucht. Mediennachweise stehen unter
`assets/SPECIES-PHOTOS.txt`, `assets/BIRD-RECORDINGS.txt`,
`assets/WILDLIFE-MODELS.txt`, `assets/attribution.json`, `web/THREE-LICENSE.txt`.
Diese Lizenzen sind getrennt; keine pauschale Lizenz aller Projektinhalte.

Physisches iPad/Safari und Unterrichtswirkung sind nicht allgemein abgenommen.
Viewport-Emulation ist kein Hardwaretest. Version und Quellcommit dieses Pakets
stehen in `build-manifest.json`.
