# Ranger 1.0 – überprüfbare Fertigstellung

Arbeitsauftrag: die vom Eigentümer bereitgestellten, bytegleichen Masterprompts
(.txt/.md). Das Pro-Review ist ein historischer Befundbericht, keine aktuelle
Testausführung. Ausgangspunkt ist `227e61e1aef850609732255859ee954f328430a9`,
Version 0.20. Arbeitsbranch: `codex/ranger-v1`. Keine Veröffentlichung freigegeben.

| Phase | Lieferumfang | Abnahme |
|---|---|---|
| 0 | portable Umgebung, Inventar, Baseline, sichere Ignore-Regeln | 22 Reihen, Build, Paketprüfung; dokumentierte Verträge |
| 1 | Paarfund/Untersuchung trennen, individuelle Pflanzen, lokale Fachhilfe, Ressourcen | positive/negative Regressionen, Altbestand erhalten |

Prioritäten: P0 = falsche Beleg-/Leistungsbehauptung oder Datenverlust;
P1 = Kernfunktion/Unterrichtsnutzbarkeit; P2 = getrennte Erweiterung.
Das quantitative Areal ist zunächst P2: freie Sichtungszahlen sind keine
Populationsdaten. Physisches iPad und Unterrichtspilot bleiben externe Prüfungen.
Keine Engineumstellung, keine Gesamtsammlung als Lernvoraussetzung, kein Konto,
Server, Bezahlwerkzeug oder KI-Bewertung. Codelizenz bleibt Eigentümerentscheidung.
